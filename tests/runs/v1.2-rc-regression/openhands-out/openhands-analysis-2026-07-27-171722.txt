BEHAVIOR SUMMARY
------------------------------------------------------------------------------
The dominant pattern is a capable, security-aware agent platform whose
strongest controls are gated behind the authenticated / SaaS deployment, while
the shipped open-source default is fail-open at the control plane. Real,
operative safeguards exist — session-key dual-auth for secret exposure,
masked-by-default secrets, secret-scrubbing structured logs, a durable
per-conversation event store, per-request-scoped integration tokens, and a
Docker sandbox that defaults to no host network and no host mounts. But in the
default OSS mode the FastAPI control plane runs with no auth dependency, binds
all interfaces (`0.0.0.0`), and reflects any browser origin with credentials,
so any party that can reach the port — or a malicious web page the operator
visits — can drive the agent to execute code in the sandbox and act on the
user's connected repositories. Secondary themes are approval gates for
high-impact Git actions that depend on a confirmation mode defaulting off in
headless use, and plaintext secret storage at rest in the default file store.
