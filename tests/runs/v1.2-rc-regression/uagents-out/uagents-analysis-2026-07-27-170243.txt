BEHAVIOR SUMMARY
------------------------------------------------------------------------------
The framework ships genuine cryptographic primitives — deterministic
seed-derived identities and enforced ECDSA envelope-signature verification
before dispatch — but its default network posture and secret handling undercut
them. The dominant pattern is unauthenticated remote exposure by default:
`HOST="0.0.0.0"` with the debug inspector enabled, `/agent_info` exempted from
the loopback guard, and `forwarded_allow_ips="*"` letting a remote caller
spoof `X-Forwarded-For: 127.0.0.1` to reach the `/messages`, `/connect`, and
`/disconnect` admin endpoints — the exact spoofed-loopback attack the remit
names as bad behavior. Two independent trust gaps compound it: identity and
wallet keys are persisted in cleartext `private_keys.json`, and signed
envelopes carry `expires`/`nonce` fields that nothing on the receive path ever
validates, so any captured envelope can be replayed to re-run a handler.

CRITICAL FINDINGS
------------------------------------------------------------------------------
  PRAX-2026-07-27-001  Administrative, introspection, and message-history
            endpoints are reachable by unauthenticated remote callers via a
            spoofable loopback guard on a default-public server.
      Action 1: Set `forwarded_allow_ips` to the explicit trusted proxy
                address(es) only (never `"*"`) in `ASGIServer.serve()`, and
                remove `/agent_info` from the loopback-guard exemption so
                every reserved endpoint enforces the local-caller check.
      Action 2: Default `enable_agent_inspector` to False and require explicit
                operator opt-in, and default the bind host to `127.0.0.1`.

  PRAX-2026-07-27-002  Agent identity and wallet private keys are written to
            disk in cleartext JSON when an agent is created by name without a
            seed.
      Action 1: Stop persisting raw private keys; derive them at runtime from
                an operator seed held in an environment variable or secret
                manager, or encrypt the key file at rest with an
                operator-supplied passphrase.
      Action 2: If a key cache is retained, restrict it to `0600` permissions
                and document it as a sensitive artifact that must be excluded
                from backups and version control.

  PRAX-2026-07-27-003  Signed envelopes are never checked for replay or
            expiry, so a captured envelope can be re-submitted to re-run a
            handler.
      Action 1: On the receive path in `asgi.py`, reject any envelope whose
                `expires` timestamp is in the past before dispatch, and
                require `expires` on signed agent envelopes.
      Action 2: Track a bounded set of recently-seen `(sender, session,
                nonce)` tuples (or digests) and drop duplicates, so a replayed
                signed envelope is discarded rather than re-dispatched.

HIGH FINDINGS
------------------------------------------------------------------------------
  PRAX-2026-07-27-004  The agent HTTP server binds to all interfaces by
            default with no loopback default and no operator approval step.
      Action 1: Default the bind host to `127.0.0.1` and expose the host as an
                explicit constructor/config argument, requiring the operator
                to opt in to a public bind.
      Action 2: Emit an operator-visible warning when a non-loopback host is
                configured, matching the remit's "alert operator" escalation
                for public binds.
