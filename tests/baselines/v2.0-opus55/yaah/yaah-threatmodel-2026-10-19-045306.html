Attacker-authored repo content gets the host agent to run code through yaah_lint
  1. Target repository contents Untrusted: attacker-authored repo text or an extracted archive (with its own node_modules/.bin or build.rs) the model reads unlabeled.
  2. Host coding agent (Claude Code / OpenCode / Codex / Copilot) [PRAX-2026-10-19-006] Hijack: steered host model calls yaah_lint with a file_path inside the attacker directory; MCP calls bypass the Bash guard.
  3. yaah MCP server (7 tools) [PRAX-2026-10-19-006] yaah_lint sets cwd = filepath.Dir(file_path) with no repository containment.
  4. Linter pipelines [PRAX-2026-10-19-006] Consequence: npx tsc/prettier or cargo clippy executes attacker code on the developer host.
Third-party skill repo pre-approves arbitrary bash in every developer's host agent
  1. Remote skill/agent repositories [PRAX-2026-10-19-013] Untrusted: third-party skill author content, fetched by ref with no content-hash check.
  2. Remote skill fetch + cache [PRAX-2026-10-19-013] Cache hit trusted by .yaah-ref marker; mutable refs accepted.
  3. Harness (hook dispatch + config generation) [PRAX-2026-10-19-005] buildSkillMarkdown writes the remote frontmatter verbatim, with no allowlist.
  4. Generated skills (SKILL.md + references) [PRAX-2026-10-19-005] Persistent: SKILL.md with allowed-tools Bash(bash:*) committed into the repo.
  5. Host coding agent (Claude Code / OpenCode / Codex / Copilot) [PRAX-2026-10-19-010] Consequence: host runs bash -c without a permission prompt; only the bypassable seven-regex guard stands between it and the shell.
Malicious skill repo copies the developer's SSH/AWS keys into the committed repo
  1. Remote skill/agent repositories [PRAX-2026-10-19-014] Untrusted: attacker repo ships references/x as a symlink to ~/.ssh or ~/.aws files.
  2. Remote skill fetch + cache [PRAX-2026-10-19-014] ScanExtraFiles follows the symlink via os.ReadFile.
  3. Harness (hook dispatch + config generation) [PRAX-2026-10-19-014] WriteAllForTarget writes the extra file under .claude/skills/<name>/references.
  4. Generated skills (SKILL.md + references) [PRAX-2026-10-19-014] Consequence: private credentials land in a tree that is typically committed and pushed.
Rug-pulled npm package runs on every edit via unpinned npx
  1. npm registry (via npx) [PRAX-2026-10-19-008] Untrusted: whatever version of prettier/typescript the public npm registry serves (typosquat or rug-pull).
  2. Linter pipelines [PRAX-2026-10-19-008] Consequence: npx -y fetches and executes it with developer privileges on each PostToolUse lint run.

Extraction Notes
lane_fit: yaah is a deterministic Go harness with no in-tree LLM call; the LLM loop where injected content becomes action is the external host coding agent, placed in client_adapters as a client node and used as the hijack step in attack paths. The hook-gate controls run inside the yaah hook process and sit in agent_core per the control-lane rule; generators fold into the harness orchestrator; no model-egress boundary exists because yaah itself makes no model call.
omissions: Edgeless node: command-advanced-command-go-control (stub control - DisableModelInvocation declared, never set). Not modelled: .claude/logs/sessions.log (session-logger writes event/session/cwd lines only, low trust consequence); LSP and Codex marketplace plugins in enabledPlugins (no finding); CI workflows and go.mod/go.sum (supply-chain mitigation cited in-boundary via .goreleaser.yaml instead of a node). Arbitration divergence: PRAX-2026-10-19-002 is stored LLM02 primary, but its evidence is gate-timing evidence (scanner registered PostToolUse only) with disclosure not evidenced, so per the KB evidence-class rule (grant/gate -> LLM03) the threat is tagged LLM03. PRAX-2026-10-19-005 backs threats at two boundaries: LLM04 at supply-chain (unvetted third-party install) and LLM03 at stored-state (statically over-broad tool grant shipped at deploy, per the Agentic KB outlive test).
