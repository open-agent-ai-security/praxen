  1. Site visitor (end user) Unauthenticated internet visitor authors the chat input.

  3. Embedded Messaging bootstrap (bootstrap.min.js) Bootstrap sends the message over the messaging session.
  4. Enhanced Chat v2 messaging deployment (SCRT) Messaging deployment delivers it to the agent.
  5. haaHelpAgent Agent Script [PRAX-2026-10-19-004] Prompt-only guardrails are the sole check; planner fills action parameters from the messages.
  6. Answer Questions with Knowledge [PRAX-2026-10-19-001] Knowledge action runs with visitor-influenced query and retriever config, no confirmation.
  7. Agentforce Data Library (search index + retriever) [PRAX-2026-10-19-007] Search index covers the whole Knowledge content field.
  8. Agent user Knowledge permission set [PRAX-2026-10-19-007] Agent-user scope is 'appropriate' visibility with no public-channel limit.

Script from an unvalidated bootstrap URL runs in the site and reads visitors' chat input
  1. Embedded Messaging bootstrap (bootstrap.min.js) [PRAX-2026-10-19-006] Script is fetched from a configured URL with no origin allowlist or SRI, so its content is unvetted third-party code.
  2. haaInlineEnhancedChat LWC [PRAX-2026-10-19-006] LWC appends it to document.body, executing it in the Experience Cloud site origin.
  3. Site visitor (end user) [PRAX-2026-10-19-006] Injected code runs in every visitor's browser with access to their typed questions and page session.
