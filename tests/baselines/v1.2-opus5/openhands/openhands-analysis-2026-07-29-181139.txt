BEHAVIOR SUMMARY
------------------------------------------------------------------------------
The dominant pattern is a well-built inner perimeter behind an open front
door. OpenHands implements genuinely careful controls where it has decided a
boundary exists — session_auth.py validates session keys only for RUNNING
sandboxes and enforces per-user ownership, the JWE registry is pinned to dir
plus A256GCM to block cryptographic agility, log handlers carry an active
secret-redaction filter, and every third-party GitHub Action is SHA-pinned —
yet the control plane those controls sit behind ships with no authentication
at all in the default self-hosted mode, because get_dependencies() returns an
empty list unless SESSION_API_KEY is set, while the documented launch command
and docker-compose.yml both publish port 3000 on every interface. The second
theme is that the repository allowlist the remit names as the primary control
on git writes does not exist anywhere in the code: create_pr and its siblings
accept a free-form model-supplied repo_name and act with the operator's stored
provider token, so the token's own scope is the only boundary. These combine
into a chain in which an unauthenticated network caller reaches /mcp — mounted
outside the router that would carry an auth dependency — and drives git writes
under the operator's credentials.

CRITICAL FINDINGS
------------------------------------------------------------------------------
  PRAX-2026-07-29-001  The V1 control plane mounts every /api/v1 route with no
            authentication in the default self-hosted mode, while binding to
            all interfaces.
      Action 1: In utils/dependencies.py, make get_dependencies() fail closed:
                when no auth mechanism is configured, return a dependency that
                rejects any request whose client address is not loopback,
                rather than returning an empty list.
      Action 2: Change the published port in docker-compose.yml to
                "127.0.0.1:3000:3000" and update the documented uvicorn
                command in openhands/server/__main__.py to bind loopback by
                default.

  PRAX-2026-07-29-002  An unauthenticated caller reaches /mcp and drives
            git-write tools that act with the operator's stored provider token
            against any repository.
      Action 1: Move the /mcp mount inside v1_router (or attach the same
                dependency list to mcp_app) so the MCP surface is covered by
                whatever authentication the deployment configures.
      Action 2: Require an authenticated user context in each MCP tool before
                resolving provider tokens, so a request with no identity
                cannot reach GithubServiceImpl at all.

HIGH FINDINGS
------------------------------------------------------------------------------
  PRAX-2026-07-29-003  No repository or organization allowlist exists in code,
            so nothing defines which git writes are in scope or which need
            approval.
      Action 1: Add an operator-configured repository and organization
                allowlist to AppServerConfig, and enforce it in mcp_router
                before any provider service is constructed.
      Action 2: Reject, rather than forward, any repo_name outside that set,
                and route the out-of-allowlist case to an explicit approval
                path instead of silently proceeding.

  PRAX-2026-07-29-004  In host-direct sandbox mode the spawned agent process
            inherits the app server's entire ambient environment, including
            every credential it holds.
      Action 1: In _start_agent_process, build the child environment from
                sandbox_spec.initial_env plus an explicit allowlist of
                required variables (PATH, HOME, SESSION_API_KEY) instead of
                os.environ.copy().
      Action 2: Bound the host-direct child's filesystem reach to the
                operator-authorized project directories rather than relying on
                the working directory alone.
